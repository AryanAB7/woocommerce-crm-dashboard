# WooCommerce CRM Integration Dashboard

A lightweight web dashboard integrating WooCommerce customer data and order tracking into a centralized CRM management interface with simulated communication workflows.

## Features
- **Customer Data Management:** Live table overview of buyer profiles.
- **Order Tracking:** Maps unique order IDs, totals, and sync status.
- **Communication Workflows:** Interactive trigger simulation for automated emails.

## How to View
You can run this locally by downloading `index.html` and opening it in any browser, or view it live via GitHub Pages.
